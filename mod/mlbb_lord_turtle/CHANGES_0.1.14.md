# v0.1.14 — Lord/Turtle names and minimap presentation candidate

Target: TFM2 0.7.2 Windows x64. Keep the user-confirmed v0.1.13 as rollback. All Lord gameplay in push.rs is byte-identical: ownership, wave timing, lane routing, nexus defenders, attack damage/timing and body-frame selection are unchanged.

English text: match kill banners/logs now say Elemental Lord and Turtle. Related team chat, objective tooltips, result counters and labels use the new names. Internal engine keys and interpolation tokens such as {Morgard}, {Serpen}, {Time} and {Count} stay unchanged. The native tooltip behavior is retained rather than describing unimplemented rewards. Other UI locales have not been comprehensively renamed.

Lord icon: a visible static portrait and small blue/red minimap PNGs are included. The separate animated combat sheet remains transparent so v0.1.13's explicit body animation continues. A client-only marker overlay tracks living lane Lords from watched match/replay snapshots. It first searches for a named minimap UI node; otherwise it uses the 320x320 minimap rectangle at (1014,677) from the user's supplied 1920x1080 HUD screenshot. Unknown canvas sizes have no guessed fallback. Projection uses the supplied standard 960000x960000 map. Marker alignment, visibility and possible native-icon duplication need an actual game test. This does not expose a new engine minimap-registration API. If placement is wrong or the icon/body changes unexpectedly, restore v0.1.13 and provide the objective log.

Turtle currently retains native Serpen gold/EXP and permanent team-stat rewards. No classic team shield or new gold/XP payout is added yet. The user chose classic MLBB gold/EXP-and-shields for the later gameplay update; CLASSIC_TURTLE_PLAN.md records that decision and the missing direct EXP-grant API. During a watched Turtle fight, a small read-only probe logs adjacent-frame gold/EXP deltas when serpen_secure increments. No rewards, save settings, simulation stats or balances are modified by this probe. The current SDK provides no direct team-EXP writer, so existing delivery must be verified before changing it.

Validation: 55 automated tests pass, including existing neutral/summoned Lord regressions, projection/origin filtering, minimap bounds and Turtle event detection. English text patches preserve formatting tokens. Windows GNU release DLL compiled with the bundled stable ABI10 SDK. The game is not available here; banner rendering and minimap placement require an in-game check.

Install: close TFM2, back up mods/mlbb_lord_turtle outside mods, replace it with this ZIP's mlbb_lord_turtle folder, enable it and restart a fresh match. The map mod stays separate. Check a Turtle kill, a Lord kill banner and a lane Lord on the minimap. Then run open_objective_log.bat and provide the log for minimap/reward verification. Revert by restoring the v0.1.13 folder.

Full source includes the SDK, Cargo.lock, asset compilers, text patches, native code, test results and build instructions. Windows build: cargo test --locked --offline --manifest-path mod/mlbb_lord_turtle/native/Cargo.toml; cargo build --release --locked --offline --manifest-path mod/mlbb_lord_turtle/native/Cargo.toml. Asset regeneration ends with compile_body_frames.py then compile_presentation_assets.py. Python/Pillow is needed only for asset rebuild, not runtime. No external messages, Workshop publication, network telemetry or generation credits were used.
