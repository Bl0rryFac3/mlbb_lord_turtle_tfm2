# Objective / allied unit sprites

The neutral Lord and Turtle assets keep the working combat tags. champions/mlbb_lord_push uses the supplied nine-frame glide for idle/run/walk and the existing Lord atlas. It is registered through explicit base champion #sheet/#anim remappings for the spawn_unit name. A transparent controller sprite is also registered for the in-simulation state fallback.
